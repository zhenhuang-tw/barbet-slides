# barbet-slides

A [Typst](https://typst.app/) slide theme for Traditional Chinese (zh-Hant-TW) law school presentations, built on [typslides](https://typst.app/universe/package/typslides). Palette, icons, layout components and global styles in one local package.

This is an unofficial personal project. Any contribution is welcomed. Requirements, installation, usage and the component reference are documented only in the Chinese README: [README-zh.md](README-zh.md).

The name refers to the Taiwan barbet (_Psilopogon nuchalis_), a bird endemic to Taiwan.
